# Ponte Fotos — acordos de manutenção

- Preserve os originais, confirmações de alterações e proteções de Live Photos. Não use mídia real em testes de mutação.
- Nunca versione `.env`, chaves, perfis, SSIDs/URLs pessoais, históricos ou staging. Use dados sintéticos em documentação, prints e vídeo.
- A identidade aprovada é o PNG gerado fornecido pelo usuário em `Assets/AppLogo.png`; mantenha o mesmo logo no app, ícone, repositório e promo. Não substitua por um redesenho SVG.
- Preferência expressa do mantenedor: **cada nova versão exige commit publicado e GitHub Release**, com tag `vX.Y.Z`, ZIP limpo, checksum, documentação em português, changelog, prints pertinentes e limitações de validação. Siga `docs/RELEASING.md`.
- Confira o código e os testes relevantes, execute validação adequada e relate evidências reais. Não afirme QA ponta a ponta com servidor indisponível.
